# @amlplugins/vercel-ai-anthropic

Native `@ai-sdk/anthropic` SDK re-exported under the `@amlplugins` namespace.

> Vercel AI SDK Anthropic provider — Claude models with tool use, prompt caching, vision, computer use.

## Install

```bash
npm install @amlplugins/vercel-ai-anthropic
```

## Use

```ts
import { /* named exports from @ai-sdk/anthropic */ } from "@amlplugins/vercel-ai-anthropic";
// or
import sdk from "@amlplugins/vercel-ai-anthropic";
```

This package additionally re-exports `ai` under the `secondary` namespace.

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
